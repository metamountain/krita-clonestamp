Clone Stamp Tool

Native Photoshop-style Clone Stamp for Krita 6.0.4 (Windows x64). After enabling this plugin and restarting Krita, the tool appears in the toolbox next to Smart Patch (stamp icon).

  • Ctrl+click: set the source point
  • Drag: paint (live)
  • Shift+drag: horizontal = size, vertical = hardness
  • Tool Options: Current Layer / All Layers, presets, brush tips, flow, airbrush, pen pressure

This plugin only loads the native tool library in lib/; it contains no Python tool. Project: github.com/metamountain/krita-clonestamp
