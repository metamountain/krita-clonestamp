Ebenen

Klick auf eine Ebene macht sie aktiv (blau). Flache Ebenen (Parallel) lassen sich per Drag in der Vorschau verschieben; Perspektiv-Ebenen werden über ihre Meter-Felder gesteuert. Standard: eine horizontale + eine vertikale Parallel-Ebene mit gleicher Zellgröße ergeben ein quadratisches Grundraster.
